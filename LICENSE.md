# Licensing

SoryOS follows the same licensing philosophy as Pop!_OS:

- **Applications**: GPL-3.0-only
- **Libraries**: MPL-2.0 (allows linking with other licenses, modifications must remain open source)
- **Foundation libraries**: MIT OR Apache-2.0 (maximum permissive)

Use SPDX identifiers in every source file: https://spdx.dev/ids/

The APT repository metadata (dists/, Packages, Release) is public data.
The packaging scripts in scripts/ are licensed under MIT.
