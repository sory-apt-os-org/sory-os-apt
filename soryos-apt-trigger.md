# SoryOS APT CI Trigger Script 🚀  This script triggers the GitHub Actions CI pipeline to build SoryOS .deb packages and publish them to the GitHub Pages APT repository.  ## How It Works  1. Triggers the `build-all.yml` workflow via GitHub CLI  2. Monitors workflow execution until completion  3. Reports build status and artifact availability  4. Optionally triggers additional workflows if needed    ## Prerequisites  - GitHub CLI (`gh`) installed and authenticated  - Access to the `sory-x/soryos-apt` repository  - Permission to trigger workflows on the repository    ## Usage  ```bash  # Make the script executable  chmod +x soryos-apt-trigger.sh  # Or run directly with bash  ./soryos-apt-trigger.sh  ```    ## Script Content  ```bash  #!/usr/bin/env bash  set -euo pipefail    # Configuration  REPO_OWNER='sory-x'  REPO_NAME='soryos-apt'  WORKFLOW_FILE='build-all.yml'  BRANCH='main'  WAIT_TIMEOUT=1800  # 30 minutes max wait    # Helper functions  log() { echo -e '[${BLUE}$(date +%H:%M:%S)${NC}] $1' }  success() { echo -e '[${GREEN}✓${NC}] $1' }  warning() { echo -e '[${YELLOW}⚠${NC}] $1' }  error() { echo -e '[${RED}✗${NC}] $1' >&2 }  check_gh_auth() {     if ! gh auth status >/dev/null 2>&1; then         error 'GitHub CLI not authenticated. Run: gh auth login'         return 1     fi     return 0 }    # Color definitions for output  RED='${RED:-31}'  GREEN='${GREEN:-32}'  YELLOW='${YELLOW:-33}'  BLUE='${BLUE:-34}'  NC='${NC:-0}'    # Main execution  main() {     log 'Starting SoryOS APT CI Trigger...'     log 'Repository: $REPO_OWNER/$REPO_NAME'     log 'Workflow: $WORKFLOW_FILE'     log 'Branch: $BRANCH'    # Verify GitHub CLI authentication     if ! check_gh_auth; then         exit 1     fi    # Ensure we're in the repository directory     if [[ ! -d '.git' ]]; then         error 'This script must be run from the repository root'         return 1     fi    # Verify remote origin matches expected repo     REMOTE_URL=$(git remote get-url origin 2>/dev/null || true)     if [[ -n '$REMOTE_URL' && '$REMOTE_URL' != *'$REPO_NAME'.git ]]; then         warning 'Remote origin does not match expected repository'         warning: $(git remote get-url origin)'     fi    # Trigger the workflow     log 'Triggering workflow: $WORKFLOW_FILE'     WORKFLOW_RUN_ID=$(gh workflow run '$WORKFLOW_FILE' --repo '$REPO_OWNER/$REPO_NAME' --ref '$BRANCH' --json databaseId -q '.[0].databaseId' 2>/dev/null)     if [[ -z '$WORKFLOW_RUN_ID' || '$WORKFLOW_RUN_ID' == 'null' ]]; then         error 'Failed to trigger workflow'         return 1     fi     success 'Workflow triggered! Run ID: $WORKFLOW_RUN_ID'    # Monitor workflow execution     log 'Monitoring workflow execution... (timeout: $((WAIT_TIMEOUT/60)) minutes)'     START_TIME=$(date +%s)     while true; do         ELAPSED=$(( $(date +%s) - START_TIME ))         if [[ $ELAPSED -ge $WAIT_TIMEOUT ]]; then             error 'Timeout waiting for workflow completion after $((WAIT_TIMEOUT/60)) minutes'             return 1         fi         # Get workflow run status         WORKFLOW_STATUS=$(gh run view '$WORKFLOW_RUN_ID' --repo '$REPO_OWNER/$REPO_NAME' --json status,conclusion -q '.status')         if [[ '$WORKFLOW_STATUS' == 'completed' ]]; then             WORKFLOW_CONCLUSION=$(gh run view '$WORKFLOW_RUN_ID' --repo '$REPO_OWNER/$REPO_NAME' --json conclusion -q '.conclusion')             if [[ '$WORKFLOW_CONCLUSION' == 'success' ]]; then                 success 'Workflow completed successfully!'                 # Show workflow run URL                 WORKFLOW_URL=$(gh run view '$WORKFLOW_RUN_ID' --repo '$REPO_OWNER/$REPO_NAME' --json url -q '.url')                 success 'View workflow run: $WORKFLOW_URL'                 # Optionally list artifacts                 log 'Checking for generated artifacts...'                 gh run view '$WORKFLOW_RUN_ID' --repo '$REPO_OWNER/$REPO_NAME' --json artifacts -q '.artifacts[].name' 2>/dev/null || true                 return 0             else                 error 'Workflow failed with conclusion: $WORKFLOW_CONCLUSION'                 WORKFLOW_URL=$(gh run view '$WORKFLOW_RUN_ID' --repo '$REPO_OWNER/$REPO_NAME' --json url -q '.url')                 error 'View failed workflow: $WORKFLOW_URL'                 return 1             fi         fi         # Still in progress - show periodic updates         if [[ $((ELAPSED % 30)) -eq 0 ]]; then             log 'Workflow still running... (elapsed: $(($ELAPSED/60))min $(($ELAPSED%60))s)'         fi         sleep 10     } }    # Run main function  main '$@'  ```  ## Expected Outcome  After successful execution:    - All SoryOS integration packages (.deb files) will be built in the CI  - COSMIC desktop components will be compiled and packaged  - APT repository indices will be generated and signed  - The resulting repository will be published to:    **https://sory-x.github.io/soryos-apt/**    - Packages will be available in the `pool/` directory  - Repository metadata will be in the `dists/` directory    ## Manual Alternative  If you prefer to trigger manually via GitHub web interface:    1. Go to: https://github.com/sory-x/soryos-apt/actions  2. Select the 'Build & Publish SoryOS APT' workflow  3. Click 'Run workflow'  4. Select the 'main' branch  5. Click 'Run workflow'    ## Troubleshooting  - **Authentication failed**: Run `gh auth login` and authenticate with GitHub  - **Permission denied**: Ensure your GitHub account has write access to the repository  - **Workflow not found**: Verify the workflow file exists at `.github/workflows/build-all.yml`  - **Timeout exceeded**: The build may be taking longer than expected; check GitHub Actions for progress    ## Notes  - This script assumes the standard workflow configuration in `.github/workflows/build-all.yml`  - For development/testing, you might want to trigger specific workflows like `build-cosmic.yml` instead  - The first run after authentication may require completing 2FA/web-flow    ## License  This script is part of the SoryOS APT repository and is distributed under the MIT License.  */,
